# 网页版 Kimi 发现页

在电脑上用浏览器刷 Kimi 发现页，顺带**把讨厌的人彻底过滤掉**。

---

## 装

### ① 装油猴

用 Chrome / Edge / Firefox 打开 `https://www.tampermonkey.net/`，装扩展。

### ② 装凭证桥接脚本

1. 点油猴图标 → **管理面板** → **+** 新建脚本
2. 内容全删，粘贴 `kimi-token-bridge.user.js` 全部内容
3. `Ctrl+S` 保存

### ③ 启动本地服务

双击 `server.py`


看到 `http://127.0.0.1:8787` 就是跑起来了。

### ④ 去官网登录

浏览器打开 **https://www.kimi.com** ，正常登录。

登录后页面左下角会出现 `凭证已送达本地发现页` —— 说明通了。

### ⑤ 打开发现页

浏览器访问 **http://127.0.0.1:8787**

开始刷吧。

## 日常用法

| 想干嘛 | 怎么做 |
|---|---|
| 刷推荐 | 打开就是，往下滚自动加载 |
| 看关注的人 | 点顶栏「关注」 |
| 看详情/评论 | 点任意卡片 |
| 发评论 / 回复 | 详情页底部输入框 |
| 点赞 | 点卡片上的 ♥ |
| 管理名单 | 点右上角「屏蔽名单」 |

屏蔽后**立刻生效**，刷新、翻页、评论展开都不会再出现他。

## 手动登录（油猴不好使时）

如果角标一直提示"连不上本地服务"：

1. 在 Kimi 官网按 `F12` → Console
2. 粘贴并运行：
   ```js
   JSON.stringify(localStorage)
   ```
3. 在里面找 `accessToken` / `refreshToken` 对应的长字符串
4. 打开 http://127.0.0.1:8787 ，点「手动填入凭证」，粘贴

## 安全说明（请务必看）

### 凭证是什么级别？

**完整账号凭证** —— 等同于你的登录态。
拿到它可以以你的身份操作 Kimi（发动态、评论、点赞等）。

所以：

- ✅ **只存本机**：`token.json` 在你自己电脑上，不上传任何地方
- ✅ **只监听 127.0.0.1**：外部设备访问不到你的服务
- ✅ **接口白名单**：服务端只放行社区相关的接口，账号/聊天/支付类一律拒绝
- ✅ **开源可审**：所有代码就在这几个文件里

### 你必须做到

- ❌ **不要把 8787 端口暴露到公网**（不要做端口转发、不要部署到服务器）
- ❌ **不要把 `token.json` 发给任何人**
- ⚠️ 在公用电脑上用完记得点「退出」（会删掉本机凭证）

### 想彻底清理

删掉 `token.json` 即可。或者点页面上的「退出」。

## 常见问题

**Q：一直提示"连不上本地服务"？**
服务没开。去本目录跑 `python3 server.py`，保持那个窗口开着。

**Q：页面显示"未登录"？**
先在 https://www.kimi.com 登录，等左下角出现"凭证已送达"，再回 127.0.0.1:8787 刷新。

**Q：凭证过期了怎么办？**
服务会自动用 refreshToken 续期。
如果 refreshToken 也过期了（一般很久），重新去官网登录一次即可。

**Q：屏蔽后他还能评论吗？**
能。这只是**你这边不显示**，改不了对方行为。
Kimi 服务端没有"禁止某人评论我"这个开关，第三方做不到。
想让他真的被处理，请用 Kimi 里的**举报**。

**Q：会不会被 Kimi 封号？**
本工具只用了正常的客户端接口，请求头照抄官方客户端，不做高频操作。
但原则上这属于第三方客户端，平台条款不鼓励。自行判断风险。

**Q：能只折叠不彻底隐藏吗？**
可以。改 `server.py` 里的 `apply_block`，把 `del` 换成打个标记，前端按标记渲染即可。
